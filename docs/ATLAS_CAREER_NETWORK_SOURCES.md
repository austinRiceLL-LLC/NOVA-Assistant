# Career network sources

Atlas Career now accepts direct job listing links from Indeed, ZipRecruiter, LinkedIn, and Handshake. Open a posting yourself, verify its title, employer, location, and availability, then use **Discover → Save a job**. Atlas stores the canonical link, ranks the details you entered against your saved preferences, and labels the listing **Verify listing**. Duplicate links update the existing card.

In **Preferences → Job networks**, each card opens that network's own job search. **Find links in synced Gmail alerts** reads up to 100 already synced Gmail messages from the past 60 days and displays direct listing links from those four networks. It does not sync Gmail itself. Review a suggested link on the original site, then add its details in Discover. Tracking redirects and search result pages are deliberately ignored, so some alerts will have no usable link.

The browser and server do not fetch these four sites as part of this feature. No scraping, automated page turns, CAPTCHA interaction, form filling, or application submission is performed for them. Atlas's existing Greenhouse, Lever, and Ashby employer board discovery remains the only automated job fetch path. Its **Run discovery** count excludes saved network links.

This integration does not imply that Atlas has Indeed, ZipRecruiter, LinkedIn, or Handshake search API access. Broader automated discovery would require an official, authorized integration for each network. A link's presence in Atlas does not prove the job is still open or that its details are correct.
